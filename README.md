# Portfolio Fandyoka

## Cara Menjalankan
1. Buka folder di Visual Studio Code.
2. Install extension **Live Server**.
3. Klik kanan `index.html` → **Open with Live Server**.

## Struktur
- index.html
- style.css
- script.js
- assets/

## Yang perlu diganti
- assets/profile.jpg
- assets/cv.pdf
- Tambahkan screenshot proyek di folder assets.
- Perbarui link LinkedIn dan GitHub.
